Android App Info (APK / Play Store)

AuraMate ek native Android application hai (web app nahi). Phone par install karne ke liye Google AI Studio ke Settings/Export menu se APK / AAB generate karke install karein, ya GitHub Releases par compiled APK upload karein.

Sabhi Installed Apps Control

Device par installed sabhi launcher apps detect karta hai aur na milne par Play Store par direct lookup kholta hai.

ChatGPT-Style Gemini Planner

Natural Hinglish ya English sentences ko samajhkar real Android intents aur actions mein convert karta hai.

Custom Name, Voice & 5 Themes

Assistant ka naam badlein, TTS voice/pitch/speed customize karein aur 5 premium M3 themes mein switch karein.

Permissions & Screen Control

Contacts, Microphone, Notifications aur optional Accessibility Screen Control (Back, Home, Scroll, Tap, Volume, Torch).

Android Phone par Run Kaise Karein?

  1. Google AI Studio mein upar/right-side Settings/Export menu se Generate APK ya Export ZIP chunein.
  2. Generated .apk file apne Android phone mein transfer karke install karein.
  3. App ke andar Commands & Perms sheet open karke Contacts, Mic, Notifications aur Screen Control allow karein.
